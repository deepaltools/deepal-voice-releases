# Deepal Voice Releases

Репозиторий раздачи готовых сборок Deepal Voice для головного устройства Deepal.

Здесь лежат только APK и сведения о версиях. **Исходный код Deepal Voice не публикуется.**

## Скачать

Последняя сборка — на вкладке [Releases](../../releases/latest).

Аккаунт GitHub и авторизация не нужны: файлы отдаются всем.

## Как ставить

Проще всего через **Deepal Store**: он сам видит новые версии и ставит их на машине.

## Про архив «Source code»

GitHub сам прикладывает к каждой метке архивы `Source code (zip)` и `(tar.gz)`.
В них лежит содержимое **этого** репозитория, то есть вот этот README и сведения о
версиях. Исходников приложения там нет и быть не может: их здесь никогда не было.
